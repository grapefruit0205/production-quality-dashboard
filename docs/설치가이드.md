# 설치 가이드 — 구글에서 처음부터 세팅하기

> 저장소 코드를 올리는 방법은 두 가지: **붙여넣기(빠름)** 또는 **clasp(자동 동기화)**.
> 어느 쪽이든 그 다음은 `설치_전체 → 설치_샘플데이터 → 설치_확인` 세 번 실행입니다.

## 0. 준비

- 구글 계정 1개 (무료). 부가기능·유료 서비스 없음.
- 드라이브 폴더를 미리 만들 필요 없음 — `설치_전체` 가 `생산품질대시보드_포트폴리오/출력` 을 자동으로 만듭니다.

## 1. 붙여넣기로 올리기 (권장)

1. 새 구글시트를 만들고 파일 이름을 `생산품질_대시보드` 로 변경
2. 시트에서 **확장 프로그램 → Apps Script**
3. 왼쪽 `Code.gs` 선택 → 내용 전체 지우기 → `설치_한번에.js` 내용을 전체 붙여넣기 → 저장(Ctrl+S)
4. 왼쪽 **프로젝트 설정(⚙)** → "`appsscript.json` 매니페스트 파일 표시" 체크
5. 편집기로 돌아와 `appsscript.json` 을 저장소의 같은 파일 내용으로 교체 → 저장
6. 함수 선택 목록에서 `설치_전체` 선택 → **실행**
   - 권한 화면이 나오면 **권한 검토 → 계정 선택 → 고급 → (안전하지 않음) 프로젝트로 이동 → 허용**
   - 본인이 만든 스크립트라 나오는 정상적인 경고입니다
7. 시트로 돌아가 **F5(새로고침)** → 상단에 `[대시보드]` 메뉴가 생깁니다

> `설치_한번에.js` 는 `Code.js` + `대시보드.js` + `설치.js` 를 합친 파일입니다. 한 번만 붙여넣으면 됩니다.

## 2. clasp 로 올리기 (선택)

```bash
npm install -g @google/clasp
```

```bash
clasp login
```

```bash
clasp create --type sheets --title "생산품질_대시보드" --rootDir .
```

```bash
clasp push --force
```

- Apps Script API 사용 설정이 필요합니다: <https://script.google.com/home/usersettings>
- `clasp create` 는 `appsscript.json` 을 기본값으로 **덮어씁니다**. 만든 직후 `git checkout appsscript.json` 으로 되돌린 뒤 push 하세요(시간대·권한 범위가 들어 있습니다).
- `clasp` 는 `Code.js` / `대시보드.js` / `설치.js` / `appsscript.json` 만 올립니다(`.claspignore`).
  **`설치_한번에.js` 는 올리지 마세요** — 같은 함수가 두 벌 선언되어 실행이 깨집니다.
- 코드를 처음 실행할 때 권한 화면이 나옵니다(드라이브·외부 URL 호출·트리거·메일). **허용**을 눌러 주세요.
- 코드를 고치면 `clasp push --force` 후 **시트에서 F5 → 함수 실행**까지 해야 반영됩니다(clasp는 코드만 올립니다).

## 3. 설치 순서

| 순서 | 실행 | 확인할 로그 |
|---|---|---|
| 1 | `설치_전체` | `탭 13개 …` / `설정 0개 중 16개 채움` / `드라이브 폴더: 생산품질대시보드_포트폴리오 / 출력` / `설치 완료` |
| 2 | `설치_샘플데이터` | `가상 생산일보 5,475행 생성 (2025-10 ~ 2026-09 …)` / `생산일보 서식: 수식 16,425개` / `집계: 월별 12행 …` / `대시보드: KPI 카드 6 / 차트 6개` |
| 3 | `설치_확인` | 12항목 진단 — 전부 `○` 이고 마지막 줄이 `=== 결과: 정상 12 / 문제 0 ===` |
| 4 | 시트 F5 → 메뉴 **[대시보드] → 리포트 PDF 내보내기** | `PDF 저장: https://drive.google.com/...` |
| 5 | 메뉴 **엑셀(.xlsx) 내보내기** | `xlsx 저장: https://drive.google.com/... (값으로 굳힌 탭 6)` |
| 6 | 메뉴 **월간 트리거 설치** (선택) | `월간 트리거 설치: 매월 1일 7시 대시보드갱신 + 리포트_PDF` |

> 2번은 실제 환경에서 1~3분 걸립니다(수식 16,425개 + 차트 6개). 6분을 넘겨 멈추면 `[중단] 시간 제한` 로그가 남고, **다시 실행하면 이어서** 씁니다.
> 4~6번은 시트 메뉴에서 실행합니다. 편집기에서 직접 실행해도 되지만, 메뉴 쪽이 결과를 대화상자로 보여줘 편합니다.

## 4. 그 다음에 하는 일

| 하고 싶은 것 | 실행 |
|---|---|
| 생산일보에 행을 추가했다 / 목표를 바꿨다 | 메뉴 **대시보드 갱신** (수식 범위 재설정 + 집계 + 카드 + 차트) |
| 리포트만 다시 보고 싶다 | `리포트작성` (PDF 없이 리포트 탭만) 또는 메뉴 **리포트 PDF 내보내기** |
| 출력 폴더를 비우고 싶다 | `초기화_출력폴더` (파일을 휴지통으로, 측정로그는 유지) |
| 샘플 데이터를 처음부터 다시 | 메뉴 **② 샘플 데이터 생성** (같은 시드라 결과가 항상 같습니다) |
| 기간을 바꾸고 싶다 | `설정` 탭 `기간_시작월`(yyyy-MM)·`기간_개월` 수정 → `설치_샘플데이터` |
| 구버전 엑셀(XLOOKUP 없음)로 열어야 한다 | `설정` 탭 `조회함수` 를 `INDEXMATCH` 로 → 메뉴 **대시보드 갱신** → 엑셀 내보내기 |
| 리포트 PDF 를 메일로 받고 싶다 | `설정` 탭 `메일알림` 에 주소 입력(비우면 보내지 않음) |
| 매달 자동으로 돌리기 | 메뉴 **월간 트리거 설치** (`설정` 의 `트리거시각` 으로 시각 변경) · 해제는 **월간 트리거 해제** |

## 5. 수작업 소요 시간 재기 (전후 비교용)

1. 메뉴 **수작업 측정 시작** (또는 `측정_수작업시작`) → 시각 기록
2. 엑셀로 같은 월별 집계표·차트·보고서 1장을 실제로 만들어 보기
3. 메뉴 **수작업 측정 종료** → 만든 건수 입력
4. `측정로그` 탭에서 자동/수작업 행을 나란히 비교

> 자동 실행 시간은 갱신·PDF·엑셀을 만들 때마다 `측정로그` 에 자동 기록됩니다. 수작업 값은 직접 재서 넣는 값이라 지어내지 않고 비워 둡니다.

## 6. 주의사항

- **회사 자료 사용 금지**: 실제 생산 실적·라인명·인명을 쓰지 않습니다. 전부 합성 데이터입니다.
- 시트 공유는 **"링크가 있는 모든 사용자 → 뷰어"** 만. 편집 권한 공개는 금지입니다.
- 무료 계정 할당량: **1회 실행 6분**, 트리거 90분/일. 샘플 데이터는 2,000행씩 나눠 쓰고 시간이 넘으면 이어서 씁니다.
- 시간대가 9시간 어긋나면: 시트 **파일 → 설정 → 시간대 (GMT+09:00) 서울**, 그리고 `appsscript.json` 의 `timeZone` 을 확인하세요.
- `.xlsx` 로 내보내면 **차트는 빠집니다**(구글 차트는 엑셀로 변환되지 않음). 집계 5탭이 본체입니다.

## 7. 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| 뭔가 안 될 때 (가장 먼저) | 편집기에서 `설치_확인` 실행 → `×` 항목을 그대로 복사해 전달. 12항목을 스스로 검사해 원인을 짚어 줍니다 |
| 메뉴 `[대시보드]` 가 안 보임 | 시트 F5 새로고침. 그래도 없으면 `onOpen` 을 편집기에서 한 번 실행 |
| `탭이 없습니다: 설정 — 편집기에서 설치_전체를 먼저 실행하세요.` | 말 그대로 `설치_전체` 를 먼저 실행 |
| `ReferenceError: SH is not defined` | 파일 로드 순서 문제(②에서 실제로 났음). 이 코드는 최상위에서 다른 파일 값을 쓰지 않도록 만들었습니다. 그래도 나면 예전 코드가 섞인 것 → `clasp push --force` 로 최신 코드를 올리거나 `설치_한번에.js` 를 다시 붙여넣기 |
| `Service Spreadsheets timed out` 로 멈춤 | 구글이 잠깐 멈춘 것. 무거운 호출은 **자동으로 3회까지 재시도**합니다(로그 `[재시도 1/2] …`). 그래도 나면 시트를 F5 하고 같은 함수를 다시 실행하세요(두 번 돌려도 데이터는 지워지지 않습니다) |
| `[건너뜀] 필터: You can't create a filter in a sheet that already has a filter` | 예전 코드의 증상. 이 코드는 기존 필터를 지우고 다시 만듭니다 — 최신 코드인지 확인 |
| `Converting from application/vnd.google-apps.spreadsheet to ... is not supported` | `getAs` 변환이 계정에서 막힌 것. 코드가 자동으로 다운로드 URL 경로로 넘어갑니다(로그 `xlsx 변환: 다운로드 URL 경로 사용`). 둘 다 막히면 구글시트 사본을 `출력` 폴더에 남기고 `[대체]` 로 알립니다 |
| 내보낸 xlsx 에 `#REF!` | 집계 탭에 수식이 남아 있을 때 생깁니다. `엑셀내보내기` 는 값을 굳힌 뒤 내보내므로 최신 코드인지 확인 |
| `설치_확인` 에 `월 칸이 날짜로 바뀜` | `2025-10` 같은 월 값이 날짜로 저장된 것. `설치_샘플데이터` 또는 `대시보드 갱신` 을 다시 실행(텍스트 서식을 먼저 준 뒤 씁니다) |
| `설치_확인` 에 `생산일보 N행 (5,475행이어야 함 — 이어쓰기 대기 중…)` | 6분 제한으로 중간에 멈춘 것. `설치_샘플데이터` 를 다시 실행하면 `[이어서]` 로 마저 씁니다 |
| `Cannot read properties of undefined` | 내부 함수(`_` 로 시작)를 편집기에서 직접 실행한 경우. 최신 코드는 "메뉴 [대시보드] → … 으로 실행하세요" 로 안내합니다. 메뉴 또는 `설치_`/`대시보드갱신`/`리포트_PDF`/`엑셀내보내기` 함수를 쓰세요 |
| 차트가 12개, 18개로 늘어남 | 예전 코드의 증상. 이 코드는 만들기 전에 기존 차트를 모두 지웁니다 — 메뉴 **대시보드 갱신** 한 번이면 6개로 돌아옵니다 |
| `설정 탭의 출력폴더ID 가 비어 있습니다` | `설치_전체` 를 실행하면 자동 입력됩니다. 폴더를 지웠다면 `출력폴더ID` 값을 비우고 `설치_전체` |
| 조건부 서식이 안 보임 | 조건부 서식은 같은 시트만 참조합니다(구글시트·엑셀 공통). 대시보드 8행의 기준값 행을 지우지 마세요 |
| 리포트 숫자와 대시보드 숫자가 다름 | 리포트는 실행 시점 스냅샷입니다. 데이터를 바꿨으면 메뉴 **리포트 PDF 내보내기** 를 다시 실행 |
| 리포트 PDF 가 2장으로 갈라지고 `5. 조치 제안` 제목만 앞장 끝에 남음 | 예전 코드의 증상입니다. 최신 코드는 행 높이를 조여 1장(45행 · 약 847px)에 담고, 내보내기 URL 에 세로 맞춤(`fith`)을 겁니다. 실행 로그의 `리포트: 예상 높이 약 …px / A4 세로 1장 978px` 로 확인하고, 넘치면 메뉴 **리포트 PDF 내보내기** 를 다시 실행하세요 |
| 리포트가 안 만들어지고 `설정 탭의 메일알림` 관련 로그 | 정상입니다. 메일 알림은 `설정` 탭 `메일알림` 에 주소를 넣었을 때만 보냅니다(기본 비어 있음 → `[건너뜀]`) |
